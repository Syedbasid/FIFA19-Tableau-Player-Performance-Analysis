# FIFA 19 Tableau Dashboard

## 📌 Project Overview
This project presents an interactive Tableau dashboard built using the FIFA 19 dataset. 
The dashboard analyzes player performance, market value, skills, and potential.

---

## 📊 Visualizations Included
1. Player Performance Analysis (Overall Rating by Nationality & Position)
2. Market Value vs Wage Comparison
3. Player Skill Analysis by Position
4. Potential vs Overall Rating Analysis

---

## 🛠 Tools Used
- Tableau Desktop
- FIFA 19 Dataset
- GitHub

---
## ✅ Key Insights
- High market value players generally earn higher wages
- Attacking players excel in finishing and dribbling skills
- Younger players often show higher potential than current ratings
- Top clubs maintain high average overall ratings
